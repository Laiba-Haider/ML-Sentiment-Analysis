# Multi-Algorithm Sentiment Analysis of E-Commerce Clothing Reviews

## Project Overview
This project aims to build a Sentiment Analysis System that automatically classifies customer reviews as Positive or Negative. The project uses Natural Language Processing (NLP) techniques and Machine Learning algorithms to analyze customer feedback from an e-commerce clothing reviews dataset.

## Dataset
Dataset Name:
Women's E-Commerce Clothing Reviews Dataset

Source:
Kaggle

Total Records:
23,485 Reviews

Features:
- Clothing ID
- Age
- Title
- Review Text
- Rating
- Recommended IND
- Positive Feedback Count
- Division Name
- Department Name
- Class Name

## Project Objectives
- Clean and preprocess customer reviews.
- Convert text into numerical features using TF-IDF.
- Train and compare multiple machine learning models.
- Evaluate model performance using standard metrics.
- Identify strengths and weaknesses of each model.

## Machine Learning Models
1. Multinomial Naive Bayes (Baseline)
2. Logistic Regression
3. Support Vector Machine (SVM)
